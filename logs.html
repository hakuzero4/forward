发送转发

使用说明

接口总览

POST /api/send发 Telegram 消息（文本 / 图片 / 话题）
POST /api/forward转发到任意 http(s) 地址
GET /api/logs查询转发记录（limit / offset / kind / status）
DELETE /api/logs清空全部记录
GET /healthz健康检查

发 Telegram 消息

curl -X POST http://127.0.0.1:8080/api/send \
  -H "Content-Type: application/json" \
  -d '{"chat_id":"-1001234567890","text":"hello"}'
chat_id *群组 / 用户 ID，群组以 -100 开头
bot_tokenBot Token（服务端未设置 TELEGRAM_BOT_TOKEN 时必填）
text消息文本（与 photo_url 二选一）
photo_url图片 URL，此时走 sendPhoto
caption图片说明，缺省用 text
message_thread_id话题线程 ID（forum topic）
parse_modeMarkdownV2 或 HTML
disable_notification / disable_web_page_preview静默发送 / 关闭链接预览

转发任意地址

curl -X POST http://127.0.0.1:8080/api/forward \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/status","method":"GET"}'

简单 GET 也可用：curl "http://127.0.0.1:8080/api/forward?url=https://example.com/status"

url *目标地址，仅支持 http / https
methodGET / POST / PUT / PATCH / DELETE，默认 GET
headers额外请求头（Host 也可指定）
body请求体字符串
timeout_ms本次超时（毫秒，上限 120000）

鉴权

设置了 RELAY_AUTH_TOKEN 后，调用需带 X-Relay-Token 或 Authorization: Bearer <token>（页面发送面板可填写并自动保存）。

curl -X POST http://127.0.0.1:8080/api/forward \
  -H "Content-Type: application/json" \
  -H "X-Relay-Token: your-secret" \
  -d '{"url":"https://example.com/status"}'

配置（环境变量）

TELEGRAM_BOT_TOKENBot Token（可选；也可在 /api/send 请求里传 bot_token）
RELAY_AUTH_TOKEN调用方鉴权 Token（建议设置）
LISTEN_ADDR监听地址，默认 :8080
TELEGRAM_API_BASETelegram API 地址
LOG_FILE记录 JSONL 文件路径（空=仅内存）
LOG_MAX内存保留记录数，默认 1000
FORWARD_ALLOW_HOSTS/api/forward 域名白名单（逗号分隔）
FORWARD_DENY_HOSTS/api/forward 域名黑名单
FORWARD_MAX_BODY转发请求 / 响应体上限（字节）

注意事项

  • /api/forward 相当于开放代理：务必设置 RELAY_AUTH_TOKEN，必要时用 FORWARD_ALLOW_HOSTS 限定目标。
  • 记录中的 Bot Token 与 token / access_token 参数会自动打码。
  • 日志页面与 /api/logs 默认不要求鉴权，建议只在内网监听或加反向代理。
  • 中继机自身需代理时设置 HTTPS_PROXY（Go 自动读取）。
